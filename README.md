# My First PR

This is a practice repository for learning how to open a pull request on GitHub.

It contains a simple example of a project README, and it's meant to be improved
one small pull request at a time.

## Goals

- Learn the GitHub pull request workflow
- Make small, safe changes
- Get comfortable with git branches

## Blockcraft

`blockcraft/index.html` is a single-file, Minecraft-style voxel game built on Three.js.
Open it in a browser (it loads Three.js and fonts from CDNs) and click **Play**.

- Endless seeded terrain streamed in 16×16 chunks: hills, mountains with snow, deserts with cacti, beaches, oceans, forests, caves and ores down to diamond
- Mine and place 19 block types, all with procedurally painted pixel textures
- Walking, sprinting, swimming, jumping and flying with block collision
- Smooth ambient-occlusion shading, day/night cycle, sun, moon, stars and drifting clouds
- Your builds, position and hotbar are saved in the browser's local storage
- Desktop (mouse lock, or drag-to-look fallback) and touch controls

Controls: `WASD` move · `Shift` sprint · `Space` jump/swim (double-tap to fly) · left-click mine ·
right-click place · middle-click pick block · `1`–`9` or wheel for the hotbar · `E` all blocks · `F` fly · `F3` debug.
